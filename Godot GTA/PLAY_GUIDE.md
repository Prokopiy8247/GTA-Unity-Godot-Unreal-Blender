# Как запустить Meridian Coast

## Windows — самый простой вариант

1. Перейдите в [Releases](https://github.com/Prokopiy8247/GTA-Unity-Godot-Unreal-Blender/releases/tag/godot-v0.1.0).
2. Нажмите **MeridianCoast-Windows-x64.zip**. Нужен компьютер с 64-битной Windows 10 или 11.
3. В папке «Загрузки» нажмите архив правой кнопкой → **Извлечь всё**.
4. Откройте распакованную папку и дважды нажмите **Meridian Coast.exe**.
5. При первом запуске подождите, пока появится город.

Редактор Godot, Blender, Python, Git и аккаунт GitHub для игры не требуются. Не запускайте EXE прямо внутри ZIP и не переносите его отдельно от остальных файлов.

У приложения пока нет коммерческой цифровой подписи. Если SmartScreen показывает «Система Windows защитила ваш компьютер», убедитесь, что архив скачан именно из указанного репозитория, затем выберите **Подробнее → Выполнить в любом случае**, если доверяете этой сборке. Не отключайте защиту Windows целиком.

### Чёрный экран или ошибка видеокарты

Закройте игру и откройте **Start - Compatibility.cmd** из той же папки. Этот вариант использует более простой графический режим. Если не помогло, обновите драйвер видеокарты и попробуйте снова. Встроенные/старые GPU могут работать медленнее. Сенсорное управление не предусмотрено.

## macOS — самый простой вариант

1. В [Releases](https://github.com/Prokopiy8247/GTA-Unity-Godot-Unreal-Blender/releases/tag/godot-v0.1.0) скачайте **MeridianCoast-macOS-Universal.zip**.
2. Дважды нажмите ZIP в «Загрузках» — Finder распакует его.
3. Перенесите **Meridian Coast.app** в «Программы» либо оставьте в распакованной папке.
4. Откройте приложение. Поддерживаются **Apple Silicon (M1/M2/M3/M4 и новее)** и **Intel**: нужная архитектура выбирается автоматически.
5. Дождитесь появления города. Для функциональных клавиш сохранения/меню может потребоваться **Fn**.

Рекомендуется macOS 14 или новее и Mac с поддержкой Metal. Это Universal 2 приложение. Для игры не нужны редакторы Godot и Blender.

### macOS не разрешает открыть приложение

Сборка имеет локальную ad-hoc подпись, но **не нотарифицирована Apple**. При первом скачивании система может заблокировать запуск.

После попытки открытия зайдите в **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение о Meridian Coast и выберите **Всё равно открыть**, затем подтвердите запуск. Делайте это только для архива из указанного репозитория, которому доверяете. Не отключайте Gatekeeper целиком.

Если написано, что приложение «повреждено», сначала скачайте архив заново и распакуйте стандартным Finder. Для проверенной сборки из этого репозитория, установленной в «Программы», можно точечно убрать метку карантина:

```sh
xattr -dr com.apple.quarantine "/Applications/Meridian Coast.app"
```

Команда относится только к этому приложению. Для другого расположения укажите его точный путь. [Почему это бывает у экспортированных приложений Godot](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_macos.html).

Если окно остаётся чёрным, для приложения в «Программах» запустите через Terminal:

```sh
open "/Applications/Meridian Coast.app" --args --rendering-method gl_compatibility --rendering-driver opengl3
```

## Первые пять минут

Вы начинаете в центре города. Подойдите к машине и нажмите **F**. Если хотите сразу попробовать лодку, самолёт или вертолёт, откройте **F1 → Vehicles**, выберите транспорт и нажмите F рядом с ним. Во вкладке Sandbox есть телепорты в порт, аэропорт, горы и другие районы.

Миссий нет. Можно гулять, ездить, пользоваться магазинами, стрелять, уходить от полиции, плавать и прыгать с парашютом. Меню F1 позволяет восстановить здоровье или включить бессмертие.

| Действие | Клавиши |
| --- | --- |
| Движение / автомобиль | WASD |
| Обзор | Мышь |
| Бег / погружение в воду | Shift |
| Прыжок / ручник | Space |
| Войти / выйти из транспорта | F |
| Взаимодействие | E |
| Присесть / укрытие | C / Q |
| Огонь / прицел | ЛКМ / ПКМ |
| Перезарядка | R |
| Оружие | Колесо мыши, 1–9, Tab |
| Камера | V |
| Карта | M |
| Парашют | P; Space — замедлить снижение |
| Фары / сигнал / сирена / радио | L / H / J / T |
| Вертолёт | WASD, Space вверх, Ctrl вниз |
| Самолёт | W/S тяга, A/D крен, стрелки вверх/вниз — тангаж |
| Пауза / меню возможностей | Esc / F1 |
| Сохранить / загрузить | F5 / F9 |

Выйти из игры: **Esc → Status → Quit game**. Сохранение происходит автоматически и при штатном выходе. На Mac системные сочетания/жесты трекпада могут мешать правой кнопке: удобнее обычная мышь.

## Где сохранения и снимки

- Windows: `%APPDATA%/Godot/app_userdata/Meridian Coast - Free Roam/`
- macOS: `~/Library/Application Support/Godot/app_userdata/Meridian Coast - Free Roam/`

Прогресс: `meridian_save.json`. Фото из меню: папка `screenshots`. Сохранения остаются на вашем компьютере, не отправляются в GitHub. Игра не требует входа в аккаунт.

## Если скачан Source code

Это исходный проект, а не готовая игра. Проще скачать игровой ZIP из Releases. Чтобы запустить исходники:

1. Установите [Godot 4.7.2 Standard](https://github.com/godotengine/godot/releases/tag/4.7.2-stable), без .NET.
2. Распакуйте исходники и найдите папку **Godot GTA**.
3. В Godot нажмите **Import**, выберите **project.godot**, затем **Import & Edit**.
4. Дождитесь завершения импорта, нажмите ▶ справа сверху (или F5 / Fn+F5).
5. Ничего вручную создавать в сцене или Inspector не нужно.

Переносимые source-launcher файлы находят Godot в PATH, рядом с проектом, в стандартной папке приложений или через переменную `GODOT_EXECUTABLE`. Если редактор установлен иначе, используйте описанный Import.
