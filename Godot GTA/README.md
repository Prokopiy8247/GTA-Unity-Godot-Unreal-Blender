# Meridian Coast — Godot GTA

Оригинальный игровой прототип свободного мира без миссий: город, транспорт, NPC, оружие и полиция. Игра создана в Godot; модели сделаны в Blender. Графика и механики экспериментальные.

## Просто поиграть

**Godot и Blender устанавливать не нужно.**

1. Откройте [готовые сборки](https://github.com/Prokopiy8247/GTA-Unity-Godot-Unreal-Blender/releases/tag/godot-v0.1.0).
2. Скачайте **MeridianCoast-Windows-x64.zip** для Windows или **MeridianCoast-macOS-Universal.zip** для Mac.
3. Полностью распакуйте ZIP.
4. Windows: откройте **Meridian Coast.exe**. Mac: откройте **Meridian Coast.app**.

[Пошаговый гайд для Windows и macOS, решение проблем и управление](PLAY_GUIDE.md)

В Releases выбирайте игровой архив, а не автоматически добавленный GitHub архив **Source code**: в Source code находится проект для редактора.

## Первые действия

- WASD — двигаться, мышь — смотреть.
- F — сесть в ближайшую машину / выйти.
- ЛКМ — стрелять, ПКМ — прицелиться, R — перезарядить.
- E — взаимодействовать; Space — прыгнуть; Shift — бежать.
- F1 — меню: вызвать любой транспорт, перейти в другой район, изменить погоду, получить оружие.
- Esc — пауза; M — карта; F5 / F9 — сохранить / загрузить.

## Что внутри

Карта примерно 11 км² с девятью районами, 14 типов транспорта, 11 видов оружия плюс кулаки, розыск 0–5, магазины, гараж, такси, плавание, полёты, парашют, сутки и погода. Это прототип: некоторые системы упрощены, возможны застревания AI.

## Открыть исходники

Установите [Godot 4.7.2 Standard](https://github.com/godotengine/godot/releases/tag/4.7.2-stable), скачайте репозиторий, откройте файл `Godot GTA/project.godot`, дождитесь импорта и нажмите кнопку ▶ в правом верхнем углу (либо F5).

Blender для запуска не нужен: все 57 моделей уже экспортированы в GLB. `GodotGTA.blend` оставлен для редактирования исходных моделей. Для разработки доступен также переносимый launcher Windows/macOS, если Godot уже установлен.

Движок Godot и его сторонние компоненты распространяются на своих лицензиях: [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt). Публикация этого проекта сама по себе не назначает лицензию сторонних компонентов оригинальному коду и ассетам.
