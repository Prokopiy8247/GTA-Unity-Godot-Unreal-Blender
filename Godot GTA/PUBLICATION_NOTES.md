# Публичная версия

Публикуется чистый снимок проекта в папке **Godot GTA**, с новой историей Git. Прежняя локальная история разработки не загружается.

Из публикации исключены локальные журналы и токенная телеметрия, служебные папки Codex/агентов, пользовательские сохранения, кэш Godot, резервные Blender-файлы, загрузочные кэши, ключи/сертификаты, файлы окружения и настройки авторизации.

Локальные абсолютные пути заменены относительными. Служебные идентификаторы сеанса удалены из отчёта; агрегированные показатели benchmark сохранены. Исходный MD-промпт сохранён без изменений. Blender-мастер проверяется отдельно, включая сохранённые пути и остатки строк в бинарных полях.

Готовые игры размещаются в GitHub Releases отдельно от исходников. В экспорт входят игровые сцены/код/ресурсы, но не отчёты, промпт, Blender-мастер, инструменты публикации или локальные журналы. Снимки и прогресс записываются в пользовательскую папку данных, а не в исходный проект.

Проверка публикации включает поиск типичных ключей/API-токенов/закрытых ключей, локальных путей и служебных идентификаторов, проверку перечня файлов и истории отправляемого коммита. Ни один автоматический поиск не является математической гарантией отсутствия всех возможных секретов; обнаруженные личные пути и метаданные удалены.

В релизах движок Godot и его зависимости сопровождаются уведомлениями об их лицензиях. Apple Developer credentials, signing keys и GitHub credentials в проект не добавляются.

## Проверка опубликованного релиза 0.1.0

- Windows EXE распакован из игрового ZIP: 37/37 smoke-проверок, отдельный графический запуск Vulkan и OpenGL Compatibility.
- Готовые загрузки дополнительно проверены GitHub Actions на Windows и macOS 14 Apple Silicon: оба задания успешны. На Mac проверены SHA-256, исполняемые права, Universal 2, ad-hoc подпись и запуск headless-игры. Отдельный графический прогон на Mac и запуск на Intel Mac не выполнялись.
- [Результат проверок](https://github.com/Prokopiy8247/GTA-Unity-Godot-Unreal-Blender/actions/runs/35349445715). Первый Mac-прогон выявил CRLF в файле контрольных сумм; файл исправлен на LF, повторный прогон успешен.
- В каждом из игровых пакетов отдельно проверены 348 внутренних файлов: исключённые документы и известные персональные маркеры не найдены.
- Публичный промпт сверен с исходным; отличается только возможная нормализация переводов строк Git.

## Дальнейшее обновление репозитория

Для будущих изменений клонируйте этот публичный репозиторий целиком и обновляйте его папку Godot GTA. Не отправляйте старую локальную историю первоначальной разработки: она намеренно не перенесена в публичную историю. Unity GTA и Unreal GTA можно добавить рядом отдельными папками.
