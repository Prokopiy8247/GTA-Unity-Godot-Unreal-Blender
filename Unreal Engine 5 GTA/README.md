# Port Meridian — Unreal Engine 5 GTA

Одиночная песочница с открытым городом, транспортом, NPC, оружием, полицией и розыском. Это экспериментальный прототип с упрощёнными системами: [подробные ограничения](FEATURE_MATRIX.md).

| Платформа | Запуск |
| --- | --- |
