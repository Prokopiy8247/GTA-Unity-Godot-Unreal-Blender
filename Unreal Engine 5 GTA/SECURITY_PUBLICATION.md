# Подготовка к публичной публикации

Проверен отдельный снимок проекта, предназначенный для папки **Unreal Engine 5 GTA**. Старые локальные коммиты в публичный репозиторий не перенесены.

## Что удалено или исключено

- Удалён токен Android File Server; сам плагин и сетевые подключения отключены.
- Локальные пути заменены переносимыми в запускателях и инструментах. Путь к личной сессии разработки удалён из инструмента расчёта метрик; он теперь принимает файл явно.
- Очищены пути происхождения во всех 70 FBX. Менялись только служебные строковые метаданные; размер файлов, структура и геометрия сохранены.
- Blender-файл проверен через blender_unreal; сохранённый каталог файлового браузера очищен, включая остаточные байты старого пути. Проверка полей ключей/паролей не нашла сохранённых значений.
- В публикацию не включены .astra-run, сессии помощника, Saved, личные сохранения, кеши, Intermediate, Binaries, настройки IDE, журналы, сертификаты, ключи и отладочные символы.
- Windows-архив собран заново в Shipping после очистки конфигурации. Из него исключены PDB, журналы, манифесты локального процесса сборки и пользовательские данные.

## Проверки

- Gitleaks 8.30.1: поиск известных форматов секретов по публикуемому дереву.
- Дополнительный поиск личного имени каталога, абсолютных локальных путей и удалённого токена, включая двоичные файлы и UTF-16.
- Проверены исходники, несжатый Blender-файл, модели, содержимое Windows-папки и файлы, извлечённые из игрового .pak.
- Исходный промпт сохранён побайтно: SHA-256 **96fa7c70ca0819822a9ba093851f93b4dd22260a7d505cc178139554941c747c**.
- Перед публикацией проверяется только новая публичная Git-история. Приватная история остаётся локально.
- В GitHub добавлен workflow проверки секретов при push и pull request. Он не требует ключей или внешних платных сервисов.

Автоматический поиск не является математической гарантией отсутствия любых чувствительных сведений. Известные найденные данные удалены; совпадений с проверяемыми личными данными и удалённым токеном в окончательной публикации не осталось.

## Повторная проверка

Из корня репозитория, если установлен Python:

```text
python "Unreal Engine 5 GTA/Tools/audit_publication.py" .
```

Gitleaks можно запускать отдельно с параметрами `dir . --redact --max-target-megabytes 100`. После нового экспорта FBX запустите **Tools/sanitize_fbx_metadata.py** и повторите проверку.

Не добавляйте в Git секреты и локальные отчёты с полными путями. Если в дальнейшем опубликуете действующий ключ, одного удаления файла недостаточно: отзовите ключ у его поставщика и очистите публичную историю.
