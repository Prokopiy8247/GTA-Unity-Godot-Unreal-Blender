# Как запустить Meridian Coast

Игра бесплатна для скачивания со страницы этого проекта. Для готовых сборок не нужны Unity, Blender, GitHub-аккаунт и навыки программирования.

## Где скачать

Откройте [релиз Unity v1.0.0](https://github.com/Prokopiy8247/GTA-Unity-Godot-Unreal-Blender/releases/tag/unity-v1.0.0). В разделе **Assets** выберите архив своей системы:

- **Meridian-Coast-Windows-x64.zip** — Windows 10/11, 64-bit, Intel/AMD.
- **Meridian-Coast-macOS-Universal.zip** — Mac с Intel или Apple Silicon, например M1/M2/M3/M4/M5. Нужна поддержка Metal; минимальная версия системы указана в приложении.

**Source code (zip)** и **Source code (tar.gz)** содержат исходники для разработчиков. Для обычной игры выбирайте архив с названием Meridian-Coast.

## Windows

1. Скачайте Windows-архив.
2. Нажмите по нему правой кнопкой мыши → **Извлечь всё**. Запускать EXE внутри ZIP не нужно.
3. Откройте извлечённую папку и дважды нажмите **PLAY.cmd** или **MeridianCoast.exe**.
4. Дождитесь появления города. Первое создание мира может занять несколько секунд.

Все папки и DLL из архива должны оставаться рядом с EXE. Установка и права администратора не нужны. Сборка не подписана коммерческим сертификатом: Windows может показать предупреждение SmartScreen. Если вы скачали именно этот релиз и доверяете ему, выберите **Подробнее → Выполнить в любом случае**. Не отключайте защиту Windows целиком.

## macOS

1. Скачайте macOS-архив и дважды нажмите ZIP для распаковки.
2. Перетащите **Meridian Coast.app** в папку **Программы**.
3. Дважды нажмите приложение. Файлы внутри `.app` перемещать не нужно.
4. Если macOS сообщает, что разработчик неизвестен или Apple не может проверить приложение: сначала попробуйте открыть его, затем откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** и подтвердите запуск именно этого приложения. Такая возможность может быть недоступна на корпоративном Mac.

Эта сборка не имеет Developer ID/нотариализации Apple. Общее отключение Gatekeeper и команды `sudo`, `spctl --master-disable` или удаление карантина для всего компьютера не требуются. Это стандартное разрешение для одного скачанного приложения; [инструкция Apple](https://support.apple.com/en-gb/102445).

Архив содержит права исполнения для macOS. Если сторонний распаковщик потерял их, сначала распакуйте ZIP стандартной «Утилитой архивирования» macOS. Если и после этого появляется ошибка доступа, в Терминале можно восстановить право запуска только основного файла приложения:

```bash
chmod +x "/Applications/Meridian Coast.app/Contents/MacOS/Meridian Coast"
```

Если приложение называется иначе или находится в другой папке, используйте его фактический путь. Не меняйте права системных каталогов. Приложение собрано как Universal: Rosetta для Apple Silicon не требуется.

## Первые действия

- Мышь поворачивает камеру, **WASD** перемещает персонажа.
- Подойдите к машине и нажмите **F**; для выхода нажмите **F** ещё раз.
- **F1** открывает Sandbox Control. Здесь можно получить транспорт и оружие, переместиться в район, сменить погоду, установить уровень розыска.
- **Esc** открывает паузу и освобождает курсор.
- **F11** включает/выключает полный экран. На Mac для функциональных клавиш может требоваться **Fn**.
- **F5** сохраняет игру, **F9** загружает сохранение. При обычном выходе состояние сохраняется автоматически.

ЛКМ — стрелять, ПКМ — прицелиться, R — перезарядить; Shift — бежать; Space — прыгнуть или открыть парашют при падении; M — карта; P — телефон. Все клавиши есть в [DEVELOPMENT.md](../DEVELOPMENT.md).

## Где сохранения и фотографии

- Windows: `%USERPROFILE%/AppData/LocalLow/Meridian Studio/Meridian Coast/`
- macOS: `~/Library/Application Support/Meridian Studio/Meridian Coast/`
- Сохранение: `meridian-save.json`; фотографии по F12: папка `Photos` в той же папке данных.

Эти файлы создаются на вашем компьютере, не требуют записи в папку установленной игры и не отправляются на сервер проекта. Обновление игры не требует удаления сохранений.

## Если не запускается

- Убедитесь, что выбрали архив для своей системы и полностью его распаковали.
- Windows: проверьте наличие `MeridianCoast_Data`, `UnityPlayer.dll` и `MonoBleedingEdge` рядом с EXE.
- Mac: открывайте целое приложение `.app`, а не отдельные файлы из его содержимого.
- Для слабого компьютера попробуйте оконный режим F11 и меньший размер окна. В F1 можно уменьшить население/трафик.
- Для обращения с ошибкой укажите систему, модель видеокарты и текст ошибки. Перед отправкой `Player.log` удалите из него личные пути и имя пользователя.

## Проверка целостности — по желанию

В релизе есть `SHA256SUMS.txt`. Его значения позволяют проверить, что ZIP скачан без повреждения. На Windows: `Get-FileHash -Algorithm SHA256 <путь-к-zip>` в PowerShell; на Mac: `shasum -a 256 <путь-к-zip>` в Терминале. Команды нужны только для проверки, не для обычного запуска.
