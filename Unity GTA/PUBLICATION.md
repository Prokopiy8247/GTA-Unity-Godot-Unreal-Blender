# Подготовка публичной версии

Публичный проект находится в `Unity GTA/`; будущие проекты других движков будут отдельными соседними папками. Исходный промпт сохранён побайтно без изменений.

## Защита локальных данных

Для публикации создано отдельное чистое дерево файлов. Старая история локального Git, журналы сеанса, пользовательские сохранения, учётные данные и локальные настройки не перенесены.

- Исключены Library, Temp, Logs, UserSettings, .astra-run, .codex, .agents, IDE-кеши и резервные отладочные каталоги сборки.
- Удалены привязка к Unity Cloud, идентификатор организации и проекта; клиентская аналитика и диагностическая отправка отключены.
- Экспортные Blender-скрипты используют путь относительно UnityGTA.blend.
- В 65 FBX нормализован абсолютный путь исходного документа; размеры полей, смещения и геометрия сохранены.
- В публичной копии Blender удалён сохранённый локальный путь файлового браузера. Геометрия и материалы не изменялись. Частная рабочая копия не заменялась.
- Добавлен обработчик сборки PublicDebugMetadata, убирающий абсолютный путь PDB из игровых DLL до упаковки и подписи приложения.
- В релизах отсутствуют персональные сохранения, скриншоты сеанса, PDB, логи, данные входа и каталоги BackUpThisFolder.
- Коммиты публичной истории используют публичное GitHub-имя и адрес noreply.

Дерево исходников проверено Gitleaks 8.30.1; дополнительно проверяются известные личные строки, пути и распакованные метаданные Blender, FBX и готовых игр. Проверка — защита от обнаруживаемых утечек, а не математическая гарантия отсутствия любых возможных секретов.

## Сборки и запуск

ReleaseBuilder создаёт Windows x64 и macOS Universal (Intel + Apple Silicon). Сборка Mono без режима Development, с LZ4HC. Исполняемые файлы macOS в ZIP имеют права 0755; полный пакет .app сохраняется. В релиз добавлен SHA256SUMS.txt.

Mac-версия имеет локальную ad-hoc подпись Unity, но не Developer ID и не нотариализацию Apple. Это объяснено в пользовательском гайде. Для запуска не предлагается отключать системную защиту целиком.

Готовые приложения запускаются без Unity Editor. F11 меняет полноэкранный режим; фотографии сохраняются в пользовательской папке Photos, чтобы установка приложения не требовала прав записи.

## Проверки

- Windows: повторный полный прогон в реальном окне, включая рендер и игровые системы.
- macOS: две архитектуры проверены непосредственно в Mach-O. Workflow `Test published Unity game on macOS` проверяет целостность архива, подпись приложения и запускает тесты на Intel и Apple Silicon.
- В режиме `-meridianHeadlessQA` семь проверок изображения явно отмечаются SKIP. Такой прогон проверяет запуск и игровую логику; он не подтверждает качество Metal-рендера, звук или поведение интерфейса Finder/Gatekeeper на домашнем Mac.

Актуальные результаты находятся в Docs/Validation и на вкладке Actions репозитория. Исторический ASTRA_FINAL_REPORT.md относится к первоначальному этапу разработки; публикация и поддержка macOS выполнены позже.

## Подтверждённые результаты публикации — 18 сентября 2026

- Windows x64: **88 PASS, 0 FAIL** при запуске из того же распакованного ZIP, который опубликован в Releases. Проверено изображение и игровая логика.
- macOS Apple Silicon: **81 PASS, 0 FAIL, 7 SKIP**; нативный запуск arm64.
- macOS Intel: **81 PASS, 0 FAIL, 7 SKIP**; нативный запуск x86_64.
- На обоих Mac прошла проверка ad-hoc подписи `codesign --verify --deep --strict` и контрольной суммы скачанного архива.
- Семь SKIP относятся только к рендеру в headless-режиме. Графика Metal, физическое управление и запуск через Finder/Gatekeeper вручную не проверялись.
- Gitleaks проверил исходники и объединённую публичную историю: обнаруженных секретов нет. Дополнительное сканирование UTF-8/UTF-16 не нашло ранее выявленных личных данных в исходниках и готовых играх.
