## Хочу просто поиграть

Откройте [Releases](https://github.com/Prokopiy8247/GTA-Unity-Godot-Unreal-Blender/releases/tag/godot-v0.1.0), скачайте архив своей платформы и распакуйте.

- **Windows:** `MeridianCoast-Windows-x64.zip` → `Meridian Coast.exe`.
- **Mac:** `MeridianCoast-macOS-Universal.zip` → `Meridian Coast.app`.

[Понятный пошаговый гайд с управлением и решением проблем](Godot%20GTA/PLAY_GUIDE.md). Редакторы для готовых сборок не нужны.

Сейчас доступен Godot-прототип **Meridian Coast**: свободный мир без миссий, транспорт, оружие, трафик и полиция. Проект экспериментальный; [ограничения перечислены здесь](Godot%20GTA/FEATURE_MATRIX.md).

## Исходники и промпт

Исходный Godot-проект, Blender-мастер и [полный промпт](Godot%20GTA/GPT-6-Astra_Godot_GTA_BlenderMCP_Prompt.md) находятся в **Godot GTA**. Проекты разных движков не смешиваются. Локальные журналы, ключи и персональная история разработки в репозиторий не включены.
